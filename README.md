# Business Analyst Portfolio

The source for my personal portfolio site: a single static `index.html` file with no build step.

## Projects featured

- **[Checkpoint](https://github.com/lenavon/10alytics-Hackathon---Checkpoint-)**: a human-in-the-loop AI prototype for hospital readmission follow-up, built for the 10Alytics Students Hackathon 2026.

## Publishing

Settings → Pages → Deploy from branch `main` / root. The site is served at
`https://lenavon.github.io/businessanalystprojects.github.io/`.
